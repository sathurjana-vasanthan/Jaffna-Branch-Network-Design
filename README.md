# 🌐 Jaffna Branch Network Design

### Cisco Packet Tracer | Networking | VLANs

## 📌 Project Overview

This project demonstrates the design of a departmental
branch office network using Cisco Packet Tracer.

The network includes multiple departments, VLAN segmentation,
Cisco switches, and centralized network servers.

## 🏢 Network Departments

| Department | VLAN | IP Network |
|------------|------|------------|
| Technical Support | 10 | 192.168.10.0/24 |
| Business Development | 20 | 192.168.20.0/24 |
| Accounting & Auditing | 30 | 192.168.30.0/24 |
| People Operations (HR) | 40 | 192.168.40.0/24 |
| Software Engineering | 50 | 192.168.50.0/24 |
| IT & Network Team | 60 | 192.168.60.0/24 |

## 🛠️ Technologies Used

- Cisco Packet Tracer
- Cisco 2960 Switches
- Cisco 3560 Multilayer Switch
- VLAN Segmentation
- IPv4 Addressing
- Network Topology Design
- Network Servers

## 🎯 Project Objectives

- Design a structured branch office network.
- Separate departments using VLANs.
- Create departmental IP addressing schemes.
- Connect departmental switches to a central multilayer switch.
- Include centralized network services.
- Develop practical networking skills.
